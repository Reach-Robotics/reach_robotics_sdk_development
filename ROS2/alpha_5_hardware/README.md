# Alpha 5 Robotic Arm Hardware Interface for ROS 2 Control

## Overview
This package provides the necessary coponents to control the Alpha 5 robotic arm through the ROS2 control framwork. It includes both the hardware interface implemented in C++ and the low-level Alpha 5 driver written in C.

## Package Contents
- **Hardware Interface (C++):**  
Implements the ROS 2 hardware interface layer that communicates with the Alpha 5 robotic arm using ROS 2 control.
- **Alpha 5 Driver (C)**  
Provides low-level communication functions and protocols to interface with the Alpha 5 hardware via serial communication.
